# Homebrew Tap for Mimiry

## Install

```bash
brew trust mimiry-com/tap          # once: Homebrew asks you to trust a tap before using it
brew install mimiry-com/tap/mimiry
mimiry --version
```

The formula is the `mimiry` command from
[mimiry-sdk](https://github.com/mimiry-com/mimiry-sdk). It is generated by that repo's release
script with every release; do not edit it here.
